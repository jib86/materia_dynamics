# Materia Dynamics

Interactive demos, pitch deck and research findings for **Materia Dynamics**, a Costa Rican AI startup that combines first-principles materials simulation with multi-agent AI.

This repository hosts static HTML pages. Each page is self-contained and opens directly in a web browser.

## Live pages

Start here: **https://jib86.github.io/materia_dynamics/**

| Page | Description |
|---|---|
| [Pitch deck](https://jib86.github.io/materia_dynamics/Pitch_Deck.html) | Company pitch (draft for discussion). |
| [Advisor findings](https://jib86.github.io/materia_dynamics/Hallazgos_Asesores.html) | Digital-twin comparables and research findings, in Spanish. |
| [Materia Faces](https://jib86.github.io/materia_dynamics/esencia_materia.html) | Rotating dodecahedron with the application areas of Materia Dynamics. |
| [Demo 1: Thermal Paste Explorer](https://jib86.github.io/materia_dynamics/demo_1.html) | Screening of candidate fillers for thermal interface materials. |
| [Demo 2: 2D Magnet Explorer](https://jib86.github.io/materia_dynamics/demo_2.html) | Exploration of 2D magnetic materials. |
