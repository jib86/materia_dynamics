Which filler should go in a better thermal paste?

A chip maker wants a thermal paste that moves heat away faster. Testing every candidate filler in the lab is slow and expensive. This page shows how the platform's agents would screen ten candidates on a computer and hand the lab only the best few.

Illustrative demo: the values come from a published study. The agents did not run these calculations for this page.

The brief

Goal: the filler with the highest thermal conductivity (κ, how well a material carries heat) at room temperature. Change the rules and the shortlist changes.

      What is real

      The computed and measured values are published results from the AFLOW high-throughput library: Toher et al., Phys. Rev. B 90, 174107 (2014). The toxic and semiconductor flags are standard rules of thumb applied by this page. The semiconductor rule is deliberately strict: real pastes sometimes use zinc oxide, for example.

      What is illustrated

      The agents did not run these calculations for this page. It shows the workflow the platform follows: screen cheaply, filter by the brief, check against known data, refine only the finalists.

      What comes next

      Hexagonal boron nitride, a common paste filler, is layered and direction-dependent, so this model does not cover it. Real paste performance also depends on loading, particle size and the interface with the polymer. That stage is where a client's own data comes in.
